## 本地运行

项目基于 Jekyll 和 Academic Pages 构建。

```bash
bundle install
bundle exec jekyll serve -l -H localhost
```

启动后可通过 `http://localhost:4000/whale/` 访问。

也可以使用 Docker：

```bash
docker compose up
```
